# End-to-end tests

Full browser flows against a running server — browsing the catalog, filling the
cart, placing an order.

Covered by Playwright via `pytest-playwright`. This stage is decided but dormant
until the server-rendered templates from [ADR 0001](../../docs/adr/0001-frontend.md)
exist and there is a page to drive. See [ADR 0005](../../docs/adr/0005-testing.md).
