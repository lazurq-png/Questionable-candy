{% comment %} The order's lines: Django's own tabular inline, restyled for this one formset (#items-group) -- shop/admin.py, OrderItemInline. A saved line's "2 x " title is printed in its candy cell instead (candy_details_widget.html), so Django's title -- positioned above the row, with 2em of padding added to make room -- is hidden, and every cell of a line is centred on one axis with the admin's usual 8px padding. A line is added through the dialog below, which a green plus at the right of the ORDER ITEMS bar opens; choosing there saves the order with the line added (shop/static/shop/admin/order_lines.js). Its own fields have no name, so they are never submitted with the order. A saved line's delete checkbox is replaced by a red X that, once confirmed in the second dialog, ticks it and saves. Django's inline script, which would make an "Add another" row, is not loaded here (shop/admin.py, OrderItemInline.media). {% endcomment %}{% load static %} {% include "admin/edit_inline/tabular.html" %}
